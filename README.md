# GS Digital Studio

Bilingual (English / Português) website for **GS Digital Studio** — websites, landing pages, business intelligence and automation.

**Tagline:** Design with purpose. Build for growth.

## Contents

- `index.html`: single-file Bootstrap 5.3.3 website, including CSS and JavaScript.
- EN/PT language switcher and localized introductory service pricing.
- Portfolio examples: Visto Certo, Professional Portfolio and Following Gabi (founder-owned projects).
- Contact form connected to Formspree.

## Form and privacy

Website inquiries are submitted to Formspree. The form asks for a name, email, selected service, project details and optional budget. Do not submit sensitive personal data. Formspree handles delivery and storage; access should be restricted to authorized administrators. The live site must be retested after deployment.

## Deployment

The repository is the version-controlled source for a static website. Hosting and domain provisioning are managed separately. The site should be published with HTTPS, then checked for responsive behavior, correct links, bilingual content and end-to-end form delivery.

## Pricing

Prices shown on the site are *starting estimates*, not binding quotes. Scope, revision rounds, deliverables, payment terms and third-party costs are confirmed in a proposal.

## Maintenance

- Edit `index.html` to change design, content, translations or form behavior.
- Test EN/PT, mobile navigation, outgoing links and submissions.
- Avoid committing credentials, customer inquiries, private documents or API tokens.
- Record deployment and major version changes in Growth HQ.
